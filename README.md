# StockPilot AI

**AI-powered swing trading analysis for smarter decisions.**

StockPilot AI is a web application designed to help users analyze stocks for short-term swing trading. It combines market data, technical indicators, machine-learning predictions, and risk analysis to produce an easy-to-understand trading signal.

> **Disclaimer:** StockPilot AI is a decision-support and educational tool. Its predictions and signals are not financial advice and do not guarantee future returns.

## ✨ Features

- 📈 **Interactive Stock Charts** — Explore historical price movement with candlestick charts and volume.
- 🤖 **AI/ML Predictions** — Estimate short-term bullish or bearish price direction.
- 🎯 **Buy / Hold / Avoid Signals** — Get a simple interpretation of the current setup.
- 📊 **Technical Analysis** — Analyze indicators such as RSI, MACD, moving averages, Bollinger Bands, ATR, and volume.
- 💰 **Trade Setup Analysis** — Identify potential entry zones, stop-loss levels, targets, and risk/reward.
- ⚠️ **Risk Analysis** — Understand volatility, downside risk, and overall setup quality.
- 🧠 **Signal Explanation** — See the key factors contributing to the generated signal.
- ⭐ **Watchlist** — Keep track of stocks you want to monitor.
- ⚖️ **Stock Comparison** — Compare multiple stocks and identify stronger setups.
- 🌐 **Market Overview** — Monitor major market indices and broader market conditions.
- 📰 **News & Catalysts** — Surface relevant company news when reliable data is available.
- 📉 **Backtesting** — Review historical strategy performance where supported.
- 📱 **Responsive UI** — Designed for desktop and smaller screens.

## 🖥️ Application

The main workflow is simple:

1. Enter a stock symbol.
2. View the latest available market information.
3. Review the price chart and technical indicators.
4. Check the AI prediction and confidence.
5. Review the Buy / Hold / Avoid signal.
6. Examine the potential trade setup and risk/reward.
7. Use the supporting analysis to make your own decision.

## 🛠️ Tech Stack

StockPilot AI is built as a modern full-stack web application.

- **Frontend:** React + Vite + TypeScript
- **Backend:** Express
- **Database:** PostgreSQL
- **ORM:** Drizzle ORM
- **API Validation:** Zod
- **Package Manager:** pnpm
- **Charts:** Interactive financial/charting components
- **Deployment:** Replit

The project is organized as a pnpm workspace/monorepo, with separate frontend, API, database, and shared packages.

## 🚀 Running the Application

StockPilot AI is currently configured for development and deployment through **Replit**.

The application can be launched and published through Replit using the project's existing configuration.

### Environment Variables

Some functionality may require external market-data services or database credentials. API keys and secrets should be configured through environment variables rather than committed to the repository.

Never commit API keys, passwords, database credentials, or other secrets to GitHub.
